# 浏览与标签交互

- 视频网格底部进入可见区域时自动请求下一页；保留加载更多按钮作为重试和手动入口。
- 正在加载、存在错误、已无下一页或处于视频页时不自动请求。重复且无法推进游标的分页结果停止自动加载。
- 前台打开视频或点击视频标签时，在恢复已有播放位置后自动播放；后台打开只新增标签。
- 视频页执行 clear 时仅清除其他标签，保留当前视频及播放状态；浏览页执行 clear 时继续清空全部标签。被清除的标签可撤销恢复。

## 验证

默认测试 18 个离线通过、4 个集成跳过，格式检查、Debug / Release 编译和签名验证通过。实际观察动态列表触底自动追加新视频，以及切换标签后进入播放状态。临时目录测试验证 clear 保留当前标签、分 P 与位置、写入后的会话以及撤销恢复，不修改真实恢复记录。
