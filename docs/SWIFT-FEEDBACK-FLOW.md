# SwiftFeedback 产品流程还原

参考本地 `makethisbetter-js` v1.30.1（MIT）。目标是在 BiliNext 当前界面指出问题，附上足够现场交给开发助手。菜单和快捷键保留用户已确定的入口；标准 macOS 交互配合原版绿色提示、垂直工具条、定位点、就地反馈卡和底部绘制说明条。

状态由一个会话负责：标注、圈画、填写、录制、可选追问、保存、失败、回执。截图和日志异步补齐，工具立即出现。输入、截图和日志不是原子采样；在窗口大小变化时保留说明，清除失效标注并重新校准。录制时撤去拦截层，让真实应用接受操作。默认不提问，不模拟云端 AI、上传、看板或邮件通知。

## 产品流程对照（2026-10-23）

| 原项目证据 | 原生实现 | 取舍 |
| --- | --- | --- |
| `widget/mode-states.ts` Idle → Annotating | 菜单/快捷键 → 原界面上的透明工具层 | 按用户约定保留原生菜单入口，不加常驻侧边按钮 |
| `annotate/toolbar.ts` 顶部提示、右侧工具条 | 顶部提示、绿色垂直标注/录制/退出工具条 | 加组件菜单作为键盘替代，不作为主要流程 |
| `annotate/session.ts` hover → pin → popup | 当前 AX 语义 + 已注册区域命中，定位点及目标附近反馈卡 | AX 可工作于未标记控件；源码行号仅来自明确注册 |
| `annotate/draw.ts` 多笔自由画笔 | AppKit 原生指针处理、完整点序列、撤销/重做 | 实际自由路径，不再以矩形替代圈画 |
| `annotate/draw-note-bar.ts` 底部说明条 | 原生说明条、撤销/重做、必带截图、取消/发送 | Esc 返回标注模式 |
| `record/session.ts` 让出页面操作，最长 60 秒 | 让出应用输入，紧凑停止条，画面序列 + 真实输入/API/状态事件 | 原生窗口不存在 DOM；明确标注每秒最多一帧，不伪称 rrweb 或流畅视频 |
| `popup/chat-popup.ts` 快捷类型、截图选择、可选追问 | 就地卡片、独立类型标签、截图勾选、可选 questionProvider | 依用户补充，默认直接保存，不强行加入 AI 或固定问题 |
| `widget/submission-lifecycle.ts` prepare/finalize/cancel/retry | 采集与输入并行；发送等待现场完成；错误保留草稿、可重试 | 本地原子目录写入替代云 API，不伪造上传成功 |
| `popup/receipt.ts` 成功、查看进度 | 成功、查看本地报告、复制交给开发助手 | 云看板、邮件通知、云端 AI/MCP 不在本次接入中 |

## 实际验证

- 本机运行原版 Vite demo，亲自检查标注入口、点选卡片、自由画笔说明条、撤销/重做、录制时让出页面、发送后的状态；同时读取状态机、提交流程、CSS 和测试。demo 的后端为仓库自带 mock，不作为真实云端 AI 能力证据。
- 新版签名 BiliNext 中：菜单/快捷键打开原界面工具层，选择卡片后出现就地反馈，保存得到 pin 坐标、源码注册点、3390×2022 原始截图和界面/业务上下文；回执可继续操作。
- 真实录制动态 → 首页，10.9 秒共 11 帧；原生预览可拖动到 5.2 秒查看加载过程，录制报告包含帧索引、JPEG、离线播放器和请求事件。
- AppKit/SwiftUI 真实 NSHostingView 的空白区 hit-test 落到原生画布，原生 mouseDown/Dragged/Up 处理提交自由路径，撤销/重做及 resize 清除旧几何保留说明均有离线回归。
- CUA 对无边框透明窗口的坐标输入返回 noWindowsAvailable，原界面自由画笔没有以该工具完成真人指针端到端验收；这与手势/命中测试分开记录。透明工具层的单窗口工具截图也不包含下方父窗口，不能用它判断整屏合成外观。

最终构建复测：一次 14.25 秒录制得到 14 帧、11 条时间线事件，类别包含 `api.request`、`recording.started/state/stopped`。`recording.state` 明确保存了“动态 → 首页”；帧和事件各自具有相对于录制起点的秒数。离线播放器包含 UTF-8 解码的内置索引，不依赖 file URL 下受限的 fetch，生成的 JavaScript 语法检查通过。

包内 37 项测试通过；主工程 281 项通过、19 项可选测试跳过。主工程与包的严格格式检查、Release、签名 Debug App、deep/strict codesign 检查通过。静态 SwiftUI 扫描无高优先级项；固定点尺寸用于复刻桌面悬浮工具/卡片与预览，主窗口几何和可访问组件选择由实际窗口驱动。未测试完整 VoiceOver 操作、多显示器、最小浮窗和所有减少效果组合，不给出完整无障碍或性能评分。
