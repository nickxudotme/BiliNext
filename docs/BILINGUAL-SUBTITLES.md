# 双语字幕

2026-10-12。在原生 mpv 播放器的「字幕与弹幕设置」或右侧「字幕」栏目，选择主字幕和第二字幕。第二字幕默认关闭，只有视频提供多条字幕轨时才显示第二字幕选择器；不提供额外的自动翻译服务。

主字幕在上、第二字幕在下，分别按照自己的起止时间显示。不会按句子编号配对，因此一条字幕的分句更长、出现空白或存在重叠时，另一条仍按自己的时间轴正常显示。右侧 Transcript 的阅读、搜索、段落、复制与跳转继续使用主字幕。

默认保留字幕文件中的原始换行。「去掉字幕内换行」是可选的本机偏好，默认关闭；开启后把单条字幕内的换行替换为词间空格，让画面字幕按播放器宽度自然换行。不会强制单行或截断长句，也不会修改加载的字幕文字、时间轴或 Transcript 原文。两条轨同时出现时，仍各自占一个文本块；同一条轨的重叠字幕仍保留独立行。

两条字幕独立加载，第二条失败时不影响主字幕，界面提供重试。快速切换、关闭第二字幕、切视频／分 P 和停止播放会取消旧请求，迟到的结果不能重新出现。更换主字幕若与第二字幕相同，会关闭第二字幕，避免同一轨重复显示。

选择第二字幕会恢复画面字幕并暂停智能去重，防止主动选择的双语被自动关闭；播放器字幕按钮仍可同时隐藏或恢复两条字幕。关闭第二字幕后重新按智能字幕规则评估。每个播放标签保留自己的第二字幕状态；切换分 P 或重新打开视频需要重新选择第二字幕。

验证：默认离线测试通过，覆盖两条时间轴、重叠／空白、独立失败与重试、旧请求取消、重复轨防止、原始换行和可选排版。签名 Release App 在 BV1Tean6pEXo 验证中文 + English 双轨、Transcript 跳转后暂停且两种语言对应；用户手动确认双语可用，并指定默认保留源换行。新增去换行选项的用户验收仍未记录。
