# 原生界面反馈原型

`Packages/SwiftFeedback` 是不依赖 BiliNext 的本地 Swift Package，接入方式和 API 见 [包说明](../Packages/SwiftFeedback/README.md)。BiliNext 的胶水代码集中在 `Sources/BiliNext/DevelopmentFeedback.swift`。

## 使用

运行 `bash scripts/build-app.sh` 后打开 `build/BiliNext.app`。在菜单栏选择「开发 → 反馈当前界面…」，或在「设置 → 开发者 → 界面反馈」录制应用内快捷键。原界面上出现提示与右侧工具条；点击组件打开就地反馈卡，拖动使用自由画笔，或先录制操作再补充说明。发送后生成本地报告和回执。

报告保存在 `~/Library/Application Support/me.nickxu.BiliNext/Feedback/`，也可从菜单打开。把整个报告目录交给 coding agent，可以同时读取描述、源码注册点、原始/标注截图、界面树、应用状态、最近事件和进程日志。原型不会自动上传或修改代码。

## 2026-10-23 产品流程重做

已将最初的独立截图编辑器替换为原界面上的工具层，完整交互对照与验证边界见 [产品流程还原](SWIFT-FEEDBACK-FLOW.md)。重点是点选/自由圈画、说明、撤销/重做、可回看的操作录制、现场打包、失败保留草稿和开发助手交接。AI 追问为可选接口，默认直接保存。

录制采用每秒最多一帧的窗口画面 + 输入/API/宿主状态变化事件，最长 60 秒、画面 12 MB、最多 2,000 条时间线事件，不含音频；报告新增 recording.json、recording/ 和离线 replay.html。区别于原版 rrweb DOM 回放，不能宣称完整还原每一帧动画。

## 两个关键实现决策

1. **源码映射采用显式组件注册。** `.developmentFeedbackTarget(...)` 透传 `#fileID`、`#line`，通过不拦截输入的 AppKit 标记视图取得实际区域。已覆盖浏览页、工具栏、视频卡片、搜索、UP 主空间、直播、播放页、播放器控制栏和侧栏。只有当前可见实例参与命中；辅助功能树补充未注册控件的语义，但不伪造其源码位置。
2. **截图使用 ScreenCaptureKit 的当前进程窗口。** 捕获实际混合窗口，保留 AppKit、SwiftUI、玻璃与 mpv 输出；不通过 SwiftUI 重绘替代实际画面。组件坐标与截图按完整窗口左上 point 对齐，像素缩放独立处理。捕获失败时保留其它上下文及明确诊断。

上下文采用通用自动采集加宿主状态提供器。BiliNext 额外提供页面/标签、播放/缓冲/字幕、mpv 诊断和构建信息；API 事件只记录路径、参数名、状态、响应大小及耗时，不保存请求头、请求体或参数值。Debug 才启用入口、监听和源码注册；Release 不启用这些采集行为。

## 首版采集能力验证（保留历史证据）

2026-10-22 至 23 日已在实际签名 Debug App 验证：菜单唤起、卡片源码定位、Retina 标注位置、真实 mpv 画面与原生界面同时截图、报告导出、快捷键冲突提示和自定义快捷键持久化。验收时录制了 `⌥⌘B`；包的默认值仍为未设置。

最终重启后，浏览页报告取得 3390×2022 截图、23 个组件、104 个 AX 节点，无不支持节点；视频卡片定位到 `BiliNext/NativeVideoGrid.swift:439`。全屏播放报告取得 3600×2260 截图，视频、弹幕与画面字幕可见，86 个 AX 节点和 61 项应用状态均保留；自由拖动框选及保存成功，退出反馈后可按 F 恢复普通窗口。

独立包 26 项测试通过，包括 AX 兼容与脱敏、组件几何/可见性、快捷键冲突、完整/无截图导出、Retina 标注像素方向和并发事件记录。主工程默认测试、Release 构建、Debug 包装、deep/strict 签名和主工程及包的严格格式检查通过。SwiftUI 静态扫描未发现高优先级问题；截图预览的 GeometryReader、固定详情列和拖动手势经原生窗口验收，组件菜单提供键盘替代操作。

重启验收曾出现 ScreenCaptureKit `-3811`，当时系统返回的窗口尺寸与 NSWindow 不一致；该失败报告仍保存了其它上下文。同期另一个任务也在重建并重启同一 App，不能据此认定唯一根因。包会对窗口身份与几何做校验；截图错误和不完整界面树必须以报告中的状态为准。

截图、应用状态和事件不是原子快照或确定性回放。日志首次查询可能花数秒；AX、日志、事件和图像尺寸有明确上限。未验证第二显示器、所有系统版本或受保护视频。报告仅在本机生成，仍可能包含私人可见内容，详细采集边界见包说明。
