# 悬停与按压反馈

参考仓库：[BewlyBewly](https://github.com/BewlyBewly/BewlyBewly)，本地 `../BewlyBewly`，本次查看提交 `d42143547bf4e9cc6864f227fcbcbd396bbff25b`，MIT 许可证。查看 `src/components/Button.vue`、`src/components/VideoCard/VideoCard.vue` 和 `src/styles/transitionAndTransitionGroup.scss`：按钮悬停改变填充、按压约 0.95 缩放，卡片通过背景和外环强调，操作元素渐入。

BiliNext 使用独立 SwiftUI 实现：`InteractionButtonStyle` 将普通控件、列表行和卡片统一为悬停填充及细描边、轻微按压缩小与释放恢复。卡片悬停上移 2pt、按压缩放 0.985；控件按压缩放 0.96。过渡约 90–160ms，未改变布局尺寸；已有液态玻璃继续保留。菜单保留原生打开行为，增加圆形边缘高亮；关闭按钮使用轻微红色反馈。

覆盖：首页/搜索/动态视频卡片、侧栏菜单与导航按钮、视频标签关闭和暂停、播放器控件、详情页选项/操作、相关推荐、字幕跳转、动态与 UP 页面常用按钮。悬停状态保存在控件内部，不驱动 AppModel 或整个瀑布流重绘；没有逐帧定时器。禁用按钮不产生悬停与按压高亮。减少动态效果时关闭位移和缩放，只保留状态色。

## 卡片与静音预览

浏览卡片采用 16:9 封面、右下角时长、头像与两行标题、作者、接口实际返回的播放和弹幕统计，悬停时出现选项菜单。搜索接口的分钟秒格式时长也可显示。历史卡片继续显示观看时间与进度。

整个窗口共用一个 `HoverPreview`。停留 450ms 后以低清请求原有单 MP4 路线，用独立的 AVPlayer 与资源桥静音播放。快速掠过不请求媒体；移开、卡片离开可视区、切页或打开视频时取消并释放。预览失败保留封面，不重复重试；卡片菜单可关闭预览。预览不创建标签、不改变主播放器位置、不执行历史上报。静音实播测试已通过。按钮时序及减少动态效果的实际观感仍需用户体验评价。
