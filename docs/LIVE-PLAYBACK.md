# 动态中的直播观看

更新：2026-10-14。

动态的「视频」和「全部」页显示正在开播的关注主播，点击后在主窗口打开保留的直播标签。「全部」动态也解析直播推荐卡片及转发中的直播卡片。没有独立直播导航、推荐页或直播搜索框。

直播复用 libmpv 渲染和现有标签生命周期，支持暂停、音量、画质、全屏、重新连接和备用 CDN。切换到其他标签或浏览页暂停直播，关闭标签释放播放器；重启只恢复房间身份，不保存有时效的播放地址，也不把直播上报为普通视频观看历史。直播不显示点播进度、倍速、字幕或分 P 控件。

## 画面滚动弹幕

实时 WSS 消息同时进入列表和画面；历史列表不作为新消息重放。画面复用 VOD 的 CoreText 纹理缓存、CALayer 线性动画和低频轨道调度，增量加入消息时保留既有图层和轨道。采用可暂停的单调显示时钟，避免直播媒体时间重置影响位置。暂停／缓冲时冻结滚动，期间到达消息只进入列表，恢复后不补播；隐藏画面弹幕仍接收右侧列表。返回浏览或切换标签停止接收。

沿用 `danmaku.*` 偏好：开关、滚动类型、字号、透明度、区域、速度和关键词屏蔽；新增画面开关和设置弹窗。显示队列最多 200 条；增量轨道保留 4096 条近期 ID，拥挤时丢弃无法安全排入的画面消息，列表保持独立。窗口或显示参数改变时重新开始画面轨道，不重放旧消息。

- 默认应用 95 项、核心 34 项测试运行通过（原有网络／硬件 opt-in 测试仍默认跳过）。新增四项增量轨道测试及两项覆盖层／实际纹理动画测试，覆盖碰撞、宽弹幕追尾、重复和旧批次、队列上限、到期清理、保留旧图层、暂停冻结和恢复动画；NSHostingView 实际装载并更新覆盖层，确认实时到达入轨和暂停期间消息不补播。
- Release 构建、签名 Debug App 打包及 deep／strict 验签通过，全部 34 个修改 Swift 文件严格格式检查通过。界面风险扫描无高风险项；GeometryReader 用于读取覆盖层尺寸，范围限定于播放器。
- 签名 App 弹幕设置弹窗实测读到既有视频偏好（26 pt、0.5×），没有覆盖原值。

- 本轮实时消息较少，未在人工截图中捕获新消息由右向左移动；画面入轨链路用真实 NSHostingView／NSViewRepresentable 集成测试验证，网络实时接收沿用上一轮已验证的 WSS 链路，不把两者合并声称为本轮完整人工验证。
