# AppModel 状态归属

AppModel 暂时保留既有 ObservableObject 接口和页面身份，避免同时改变视图订阅、标签恢复与滚动行为。`AppModelScope` 明确实例是工作区还是页面；旧初始化参数保留兼容，内部页面通过统一工厂创建。

| 归属 | 内容 | 生命周期 |
| --- | --- | --- |
| 工作区 | 标签列表、选中项、关闭记录、窗口状态、页面实例及订阅、Now Playing | 随工作区 |
| 共享服务 `AppModelServices` | API、SessionStore、下载、悬停预览、播放预取、请求加载器、字幕偏好、关注直播缓存、历史发送队列、稍后再看同步 | 一个工作区及其页面共用；不同工作区独立 |
| 浏览页面 | 查询、排序、列表、分页、错误、缓存和请求代次 | 随保留页面 |
| 播放页面 | 播放器、时钟、恢复流程、字幕、弹幕、评论、交互和请求代次 | 随视频标签 |

共享服务不是全局单例，不保存页面列表或播放器。服务通过弱引用访问拥有者，用于历史队列的账户校验和成功刷新；不持有工作区。播放进度上报器仍属于页面，所有页面向同一个历史队列提交。

账户 profile 和请求代次由共享 `AppAccountState` 持有。所有页面读取同一份账户状态；AppModel 转发账户的 objectWillChange，保留已有 SwiftUI 观察入口，不再在启动、页面连接或激活时复制 profile。账户代次变化仍重置关注直播及稍后再看同步；历史队列继续通过弱拥有者校验账户。收藏夹元数据和登录/注销编排仍由工作区维护。

创建浏览页或播放页时，使用已有服务对象，禁止先创建独立服务再通过赋值补接共享实例。可注入的加载器和偏好同时继承，避免测试或配置在子页面中回落到默认网络/存储。字幕模型本身仍每页独立。

验证见 `Tests/BiliNextTests/AppModelOwnershipTests.swift`、`AppAccountStateTests.swift`，以及现有持久浏览、标签、关注直播、稍后再看、历史与字幕回归测试。


# 网格公共行为

`VideoGridInteraction` 统一管理滚动标记、停止预览与 150ms 空闲复位。网格退出时先取消定时工作，再按现有流程异步发布复位，避免 updateNSView 同步触发 SwiftUI 更新。NSCollectionView 首页布局与空间页的固定几何布局仍各自实现，不合并分页和回收机制。

本轮不删除仍用于播放、悬停和集成测试的兼容路径，也不将 OpenGL 播放层替换为新的渲染引擎。相关弃用警告单独保留，避免在结构整理中改变媒体与鉴权行为。
