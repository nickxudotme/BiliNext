# 2026-10 体验重设计：Arc 外壳与 B 站式细节

分支 `design/glass-redesign`。目标是让 BiliNext 在细节上不输官方客户端，同时把 macOS 26 液态玻璃真正用起来。方向经用户确认：先做基础与外壳，窗口底层透出壁纸，卡片悬停用原生轻抬起；要做的官方功能为一键三连长按、窗口置顶／小窗、官方快捷键与高能进度条。

## 参考来源

- 官方哔哩哔哩 macOS 客户端（本机 1.17.9 包，Electron + Vue）：REA `analyze-javascript-application` 列出渲染层模块（骨架屏、空状态、主题 token、置顶等），样式数值读自 `app.asar` 的 CSS 与播放器内核。只记录设计数值与交互行为，未复制代码或素材。
- Arc 1.117.0（原生 Swift）：只读资源目录、本地化字符串、类名与自带新手引导视频；本机窗口截图因不在当前 Space 未取得，测量来自引导视频帧。未交互、未复制代码或素材。
- 对本仓库 UI 的逐文件审计：写死字号 22 处／11 种、字面量圆角 21 处、悬停透明度三种、动画时长八种、封面五套实现、品牌色未全局生效、进度条为系统 Slider、自建红绿灯在侧栏隐藏后消失。

## 设计原则

1. 原生骨架，B 站的克制。窗口结构遵循 macOS 26：系统红绿灯、壁纸透出的底层、同心圆角的内容卡片。细节规则学官方：三档文字灰、0.2s 为主的动效、粉色只表示状态。
2. 粉色只用于状态：激活的图标、已点的互动、进度、悬停中的标题、开启中的播放器开关。静止界面保持中性。
3. 选中即“内容卡片的一小块”（Arc）：侧栏选中行与内容卡片同底色并带发丝阴影；卡片内的分段选中用抬起的 `raisedFill`。
4. 每个状态都设计：首屏骨架屏、统一错误横幅、按页面说明的空状态、封面淡入。

## 系统（GlassTheme v2）

- 字号：页面 26 粗、弹窗 20 粗、分区 17 半粗、阅读 16、正文 15、控件 14、辅助 13、密集 12；图标 11 / 15 / 18。
- 圆角：角标 4、行 8、封面 12、浮层 16、内容卡片 10（距窗口 8pt）。
- 颜色：`accent` 浅色 #FF6699、深色 #ED5C8C；`canvas` 为 `textBackgroundColor`（浅色纯白）；`raisedFill` 浅色白、深色白 16%。
- 反馈：悬停 7%、按下 14% 并缩放 0.95；卡片不画底板，改为抬起、封面阴影加深和图片 4% 放大。
- 动效：`Motion.quick` 0.1s、`panel` 0.08s（Arc 侧栏曲线）、`standard` 0.2s、`emphasized` 0.3s easeInOutCubic，均尊重减弱动态效果。

## 外壳

- `WindowBackdrop`（`NSVisualEffectView`，behind-window）铺满窗口；固定侧栏直接画在上面，边缘唤出的侧栏为玻璃浮层。
- 内容区是嵌入卡片；全屏与小窗时去掉间距与圆角。
- 系统红绿灯常驻，侧栏头部 32pt 与其居中对齐；侧栏隐藏时浮在卡片左上角。
- 卡片工具栏（`BrowseToolbar`）由所有浏览页共用：首页分区与动态模式为滑动分段，其余页显示标题；右侧搜索胶囊点击才变为输入框，回车打开搜索页。侧栏只保留收藏夹子项。

## 侧栏标签（Arc Today）

封面缩略图带观看进度与直播红点；悬停 200ms 后在侧栏右侧弹出玻璃预览卡（大封面、标题、UP、“看到 mm:ss / 时长”或直播中），在相邻标签之间移动立即切换，离开标签区 120ms 后收起，与 Arc 的 `SidebarPreviewHoverTracker` 一致；播放中显示音波，后台打开未看显示粉点；悬停时标题尾部淡出并出现关闭；分隔线旁悬停出现「清除」；右键可关闭其他／下方标签。快捷键：⌃Tab / ⌃⇧Tab、⌘1–8、⌘9 最后一个、⌃⌘S 侧栏。侧栏隐藏时后台打开会提示。

## 浏览与卡片

标题 15 中等、悬停变粉；作者行加发布日期（刚刚／N分钟前／N小时前／昨天／MM-dd／yyyy-MM-dd）；封面统计、弹幕与时长同排；历史封面底部进度条；悬停出现玻璃「稍后再看」和选项按钮。首屏为与网格同尺寸的流光骨架屏。

## 播放页

- 进度条（`PlaybackScrubber`）：4pt 轨道悬停加粗到 6pt、mpv 缓冲区间、悬停弹出圆点与时间气泡、拖动定位；悬停控制栏时在上方显示高能进度条（`bvc.bilivideo.com/pbp/data`，无凭据，设置中可关）；控制栏隐藏后保留 2pt 进度线。
- 控制栏固定深色外观；画面中部停留 1.2s 隐藏、边缘 3s、离开立即隐藏，进出对称动画。音量图标随音量变化，悬停展开滑条。
- 快捷键：空格、←/→ 5s、长按 → 2× 倍速、↑/↓ 音量、M 静音、F 全屏、D 弹幕、[ ] 分 P、Q 点赞、W 投币、E 收藏。
- 互动栏：点赞、投币、收藏、分享显示计数，已操作变粉；长按点赞 0.8s 环形进度后一键三连，三个图标一起弹跳。状态在模型中，剧场模式下快捷键同样可用。
- 置顶（⌥⌘P）与小窗（⌥⌘M，480×270 右下角，Esc 退出）；退出后恢复窗口位置、侧栏、详情与置顶。
- 详情面板与卡片同底色；元信息显示播放、弹幕与 BV 号；推荐带时长与播放数；评论时间与点赞数按 B 站格式。直播控件同步深色方案与样式。

## 评论区（2026-10-14）

- 结构改为 B 站的两层：一级评论左侧头像列、右侧身份／正文／图片／元信息；楼中楼前三条在浅底块内预览，「共 N 条回复 ›」在面板内推入评论详情页，回复平铺按时间排列，属于对话链的回复带「查看对话」再推一层。取代原来自建的多层缩进树。
- 正文还原表情图片、@ 提及、关键词搜索链接、BV 号与时间点：时间点跳转播放位置，BV 号打开视频（⌘ 为后台标签），关键词打开搜索。超过接口给出的行数（通常 6 行）时折叠并显示「展开」，按当前宽度计算是否真的被截断。
- 身份：大会员名字颜色、LV 等级、UP 徽章、置顶、「UP 觉得很赞」、IP 属地。图片单张按比例显示，多张三列网格，点开为深色大图查看器（←/→ 翻页）。
- 操作安静：只读，常驻只有时间与点赞数，「…」悬停出现；最热／最新用滑动分段；向下滚动自动加载。评论点赞（账号写操作）留作下一步。

## Arc 原生逆向（Ghidra 12.1.4，2026-10-14）

在 Arc 1.117.0 的 arm64 切片上用 Ghidra headless 分析（本机自编 arm64 反编译器），只读取常量与调用结构，不复制代码：

- 侧栏显示／隐藏／浮出（`WindowLayoutController` 改 `sidebar`、`floatingSidebarContainer` 帧与透明度）：0.08s，`cubic-bezier(0.25, 0.46, 0.45, 0.94)`。另有 0.12s 线性往返的提示动画和 0.2s 的容器重新布局。
- 侧栏行悬停预览（`SidebarPreviewHoverTracker`）：`DispatchWorkItem` 延迟 200ms；预览出现后在相邻行之间移动不再重新等待（记录 `lastCommittedHover`）。
- 分区标题（含「Clear」）淡入淡出 0.1s easeOut；标签行状态 0.1s easeInEaseOut；Clear 按下 0.175s；可悬停控件的高亮渐隐 0.4s。
- 全部 `setDuration:` 调用中最常见的是 0.1s，其次 0.2s、0.08s、0.12s，0.3s 很少。Arc 整体比我们原来的 0.15–0.2s 更快。
- 浮动侧栏有三块边缘悬停区：窗口外左缘、窗口内左缘，以及左上角红绿灯一带。

据此调整：`Motion.quick` 改为 0.1s；新增 `Motion.panel` 用于侧栏固定／唤出；侧栏隐藏时，指针停在左上角（96×32pt，红绿灯旁）也会唤出侧栏。唤出前的等待（180ms）与离开后的宽限（400ms）仍为原值：Arc 的这两个数值由配置传入，静态分析未取得，需要动态观察才能确认。
