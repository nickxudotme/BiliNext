# 视频网格动效与预加载

本轮给原生视频网格增加短错列入场和有上限的分页缓冲。采用expressive发现页的单一动效，周边导航继续保持克制。保留卡片尺寸、现有点击／右键／悬停预览、侧栏和播放页面交互。

## 动效

- 首次出现、成功刷新和滚动到尚未展示的卡片时，按可见顺序淡入并轻微位移6pt。
- 每张卡片280ms，同批最多错开280ms；根据可见卡片数量分配间隔，不让列表后面的卡片越等越久。
- 同一轮列表中，每个视频只播放一次入场；成功刷新后允许同样的视频重新入场。请求失败时不重播旧内容。
- AppKit Collection View继续负责复用和滚动。动画只改变显示层，卡片布局及命中区域保持原位置。
- 离屏、复用、页面失活和开启Reduce Motion时取消动画，回到完整可见状态。Reduce Motion直接显示内容，不增加位移或等待。

## 刷新与加载

- 首次加载和刷新最多连续取3页；第一页成功后立即显示，后续页陆续追加。
- 距离列表底部约一个视口时，最多取2页。单个页面同一时刻只有一批请求，自动加载遇到错误会停止。
- 推荐、热门、搜索在空页或完全重复页停止；动态、收藏、历史和稍后再看遵循接口的下一页信息，允许经过过滤后为空的页面。
- 相同／循环游标、无效或倒退页号会结束加载。排行榜只取一页。
- 刷新取消旧请求，过期结果不能修改列表、游标、错误或加载状态。追加沿用成功提交的查询条件，未提交的输入不会混入旧列表。
- 首屏失败保留缓存并重新尝试第一批；后续页失败保留已加载内容，从失败的下一页继续。连续空页仍有后续内容时，空状态提供“继续加载视频”。
- 触控板在顶部下拉超过56pt、松手后刷新，显示“下拉刷新／松开刷新／正在刷新”。距离根据直接滚动输入累计，反向拉回可取消；离开顶部后取消手势，不依赖弹性滚动的显示层或bounds是否变负。惯性滚动不触发，加载中不重复排队。

## 二级页面保留

- 推荐、热门、排行榜、番剧以及动态的视频／全部模式分别保留页面实例；每个收藏夹也有自己的页面。回切保留列表、分页游标、筛选条件、滚动位置和卡片入场记录。
- 首次进入才加载。已有内容、空结果、错误状态以及正在加载中的页面回切都不重新请求；刷新和重试仍能主动更新。
- 切换到接近底部的旧位置不会自动追加内容；继续滚动接近底部时正常加载。首次数据加载完成后仍可自动补足短视口。
- 前进／后退记录二级节点，视频后退先回到原浏览页。启动时迟到的账号信息只补齐尚未加载的页面，不刷新已加载列表或重新加载视频。
- 登录／退出取消旧列表请求并移除旧页面实例；新实例重新挂载，避免旧网格和动态内容被跨账号复用。默认收藏夹解析出真实ID后仍使用同一页面实例。

## 验证

- 分页和动效测试之外，新增二级页面复用与原生网格返回回归测试。完整测试通过（App 77项、Core 20项，其中11项可选联网／媒体测试跳过）；覆盖先展示第一页、3／2页预算、去重、游标循环、过滤空页、失败续取、取消和过期结果，以及推荐↔热门、收藏夹别名、完整二级路由、启动竞争、空／错误／加载中页面回切、近底部回切与实际滚动加载。
- 修改文件通过严格格式检查；全项目格式检查仍有3个未修改文件的既有诊断（InteractionStyle、ThumbnailView、MPVPlaybackTests），本轮没有扩展修改范围。
- Release编译通过。原有OpenGL弃用和libmpv最低系统版本链接警告仍在；本轮没有修改媒体依赖。
- 二级页面修复的Debug App已重新打包，deep／strict签名验证通过，启动登录状态保留。
- 独立真实WindowServer采样运行了6张实际Collection View卡片：75ms时opacity约为`[.457,.286,.097,0,0,0]`，159ms时为`[.795,.669,.522,.358,.176,0]`；651ms全部为1，动画已移除，model层始终为1。临时采样窗口在屏幕外且不激活，采样进程全部退出。
- 最终签名App真实暗色窗口检查了视频动态、推荐、连续刷新、滚动复用、追加内容、历史及默认收藏夹；登录状态保留。保留用户当前页面和标签。
- 二级页面修复后，真实Shell与AppKit网格的离屏窗口验证：推荐650pt、热门350pt分别保留；推荐回切revision仍为1，既有卡片没有新入场动画，请求数为0。近底部1542pt回切请求数仍为0，继续滚动20pt才请求下一页。普通视频返回保持原网格和位置。
- 同一主线程轮次移除旧页面并重建相同路由的验证通过：新网格／coordinator绑定新实例，旧coordinator停用，挂载网格数量为1。
- 最终签名App窗口中，推荐↔热门、重复点击当前子页以及前进／后退均保留相同可见卡片；推荐滚动条0.2777425491439442、热门0.2547993019197208在各自回切后完全一致。主动刷新热门回到顶部并更新内容，推荐保持原内容和位置。
- 视频返回的独立真实Shell验证包含新建PlaybackView、发布详情及原生卡片鼠标事件，scrollY全程保持950、请求数为0。用户在最终签名App中手动滚动推荐、点开视频并后退，确认位置保持不变。桌面工具的卡片点击曾出现位置变化，已有标签激活返回正常；该工具路径差异没有据此扩大修改播放器或焦点逻辑。
- 前期动效实现的SwiftUI静态扫描无high项，原有80个medium／6个low提示数量未增加。本轮没有改动API、登录存储、签名配置或参考项目。
- 桌面工具滚轮不能复现完整触控板手势；实际下拉手感、完整VoiceOver／浅色／高对比矩阵及Instruments帧率采样尚未验证。不宣称固定帧率。
