# BiliNext 设计语言

2026-10-14 起。BiliNext 的内容和使用习惯随 B 站，外观随 macOS 26，个性来自视频本身。目标是液态玻璃的质感和高级、精致的观感，而不是另一个官方客户端。

## 借什么，不借什么

- **借**：信息结构和用语。简介页的顺序、合集与分P互斥、两层评论、三连、`[ ]` 切 P、Q/W/E、「1.2万」计数。这些是 B 站用户的肌肉记忆。
- **不借**：官方的皮肤。灰底圆角卡片、粉字加粉底的当前项、照搬的 CSS 尺寸（141×79、50×60 等）、清一色 12–16px 的字号。这些属于网页客户端，换成 macOS 的写法。

## 原则

1. **玻璃承载浮层，内容保持清晰。** 导航、详情面板、控件、弹出层用液态玻璃；封面、正文和视频画面放在不透明或高对比的表面上。不在玻璃上再叠玻璃。
2. **视频即色彩。** 界面本身保持中性，颜色来自正在看的视频：播放页用封面做环境光，玻璃面板透出它。每个视频的页面都不一样。
3. **粉色只给「你」。** 你点过的赞和投币、你的观看进度、正在播放的标记。静止的界面里不出现粉色色块。
4. **层次靠字号和透明度，不靠色块。** 标题大而稳，元信息小而淡；分组靠分组标题和细分隔线，不靠底色盒子。
5. **安静的默认。** 次要操作在悬停时出现；选中项用抬起的浅色底，不用描边。
6. **原生的动效。** 状态变化用弹簧（`snappy` / `smooth`）；侧栏和悬停反馈沿用 Arc 测得的 0.08s / 0.1s；尊重减弱动态效果与降低透明度。

## 表面

| 表面 | 用法 |
| --- | --- |
| 窗口底层 | 透出桌面壁纸的材质，侧栏直接画在上面 |
| 内容卡片 | 浏览页的不透明画布，距窗口 10pt，圆角 10 |
| 播放页 | 深色影院模式：封面大幅模糊后的环境光铺底，视频在左 |
| 详情面板 | 悬浮在环境光上的液态玻璃，距卡片边缘 8pt，圆角 16 |
| 播放控件 | 一整条悬浮的液态玻璃控制条：距画面左右 18pt、底部 16pt，圆角 22（小窗 16），最宽 1040pt，进度条和按钮都在条内；点播与直播共用 |
| 控件与浮层 | 玻璃胶囊或圆形；画面上的控件固定深色 |
| 浏览工具栏 | 悬浮在内容卡片顶部的玻璃胶囊（分区切换、搜索、筛选、排序、正在直播），下方垫一层向下淡出的柔和材质；网格从它下面滚过 |

## 浏览页

- 页面自己的控件都在工具栏里，不在内容上方另起一行。
- 搜索不占侧栏一行：工具栏右上角的搜索框（⌘L）是唯一入口。
- 错误提示悬浮在工具栏下方，「已移除，撤销」悬浮在底部，都是玻璃。

## 字号层级（播放页）

- 视频标题 20 半粗，行距 3。
- 分组标题 13 半粗、次要色，例如「合集」「视频选集」「相关推荐」。
- 正文 14–15，元信息 12 次要色，计数用等宽数字。

## 列表与当前项

- 分组之间用细分隔线，组内行没有底色。
- 悬停：抬起的浅色底（`raisedFill` 的一半强度），圆角 8。
- 当前项：抬起的浅色底 + 半粗正文 + 粉色音波；文字本身不变粉。

## 与之前的区别

2026-10 前几轮为了对齐官方，简介、评论和播放器借用了官方的视觉数值；按本文逐步替换。信息结构保持不变。
