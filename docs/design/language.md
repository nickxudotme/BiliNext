# BiliNext 设计语言

2026-11-22 更新。BiliNext 保留现有窗口构型、导航和 B 站使用习惯，以流畅、清晰、低渲染开销为优先。个性来自视频内容，统一感来自排版、间距、选中态和交互反馈。

## 借什么，不借什么

- **借**：信息结构和用语。简介页的顺序、合集与分P互斥、两层评论、三连、`[ ]` 切 P、Q/W/E、「1.2万」计数。这些是 B 站用户的肌肉记忆。
- **不借**：官方的皮肤。灰底圆角卡片、粉字加粉底的当前项、照搬的 CSS 尺寸（141×79、50×60 等）、清一色 12–16px 的字号。这些属于网页客户端，换成 macOS 的写法。

## 原则

1. **纯色承载界面。** 自定义导航、详情面板、控件和浮层使用不透明表面；不使用自定义液态玻璃、实时背景模糊或窗口壁纸采样。系统菜单和弹窗保留系统行为。
2. **视频即色彩。** 界面本身保持中性，颜色来自封面和视频画面；播放页使用稳定深色背景，不额外解码封面来生成环境光。
3. **粉色只给「你」。** 你点过的赞和投币、你的观看进度、正在播放的标记。静止的界面里不出现粉色色块。
4. **层次靠字号和透明度，不靠色块。** 标题大而稳，元信息小而淡；分组靠分组标题和细分隔线，不靠底色盒子。
5. **安静的默认。** 次要操作在悬停时出现；选中项用抬起的浅色底，不用描边。
6. **原生的动效。** 状态变化用弹簧（`snappy` / `smooth`）；侧栏与内容区由保留的原生宿主共用 0.08s、控制点 `(0.25, 0.46, 0.45, 0.94)` 的过渡时间线，参数来自本机 Arc 的静态分析。页面先采用目标布局，再由 Core Animation 过渡外层几何；不逐帧发布布局进度。悬停反馈使用 0.1s；尊重减弱动态效果与降低透明度。全屏实测仍有布局卡顿，不能把参数一致等同于流畅度一致。

## 表面

| 表面 | 用法 |
| --- | --- |
| 窗口底层 | 系统窗口背景纯色，侧栏直接画在上面 |
| 内容卡片 | 浏览页的不透明画布，距窗口 10pt，圆角 10 |
| 播放页 | 深色影院模式：固定深色铺底，视频在左 |
| 详情面板 | 不透明深灰表面，细边界区分层次，距卡片边缘 8pt，圆角 16 |
| 播放控件 | 一整条悬浮的不透明深色控制条：距画面左右 18pt、底部 16pt，圆角 22（小窗 16），最宽 1040pt，进度条和按钮都在条内；点播与直播共用 |
| 控件与浮层 | 纯色胶囊或圆形，加细描边；画面上的控件固定深色 |
| 浏览工具栏 | 位置与高度保持不变；纯色胶囊承载分区、搜索、筛选、排序和直播入口，工具栏使用不透明背景与底部分隔线；网格从它下面滚过 |

## 浏览页

- 页面自己的控件都在工具栏里，不在内容上方另起一行。
- 搜索不占侧栏一行：工具栏右上角的搜索框（⌘L）是唯一入口。
- 错误提示悬浮在工具栏下方，「已移除，撤销」悬浮在底部，均使用不透明表面。

## UP 主个人页

- 和视频、直播一样是侧栏标签，标签行用圆形头像代替封面。
- 头部：UP 主自己的横幅向下淡入画布，没有横幅时使用中性底色；96pt 头像压在横幅下缘。名字 26 半粗，等级、大会员是中性胶囊，认证用印章图标。
- 操作是纯色胶囊。「关注」保持中性，已关注时才用粉色勾；取消关注需要确认。
- 分区栏（投稿／合集和系列、搜索、排序）保留悬浮和吸顶行为，吸顶时垫上纯色工具栏背景和分隔线。
- 合集卡片用两层后退的薄片表示「一叠视频」，右下角是数量。

## 字号层级（播放页）

- 视频标题 20 半粗，行距 3。
- 分组标题 13 半粗、次要色，例如「合集」「视频选集」「相关推荐」。
- 正文 14–15，元信息 12 次要色，计数用等宽数字。

## 列表与当前项

- 分组之间用细分隔线，组内行没有底色。
- 悬停：抬起的浅色底（`raisedFill` 的一半强度），圆角 8。
- 当前项：抬起的浅色底 + 半粗正文 + 粉色音波；文字本身不变粉。

## 与之前的区别

2026-10 前几轮为了对齐官方，简介、评论和播放器借用了官方的视觉数值；按本文逐步替换。信息结构保持不变。


## 性能基线与实现边界

- 本轮只调整表面与装饰，不重构页面、不调整播放状态和导航逻辑。保留轻量悬停、按下、选中反馈，以及封面本身的渐变遮罩。
- 大面积详情和控制条阴影去掉；抽屉与标签预览的阴影缩小。
- `GlassTheme`、`floatingGlass`、`playerGlassBar` 等既有内部名称暂时保留，但实现已是纯色，不再创建玻璃效果。
- 纯色表面天然满足降低透明度的基本需求；增加对比度仍提高控件与面板边界，减弱动态效果继续沿用原有处理。
- 不将效果移除等同于卡顿根因已确认。性能收益需在同一构建配置、视频、窗口大小和操作下比较；当前未给出帧率或功耗提升比例。
