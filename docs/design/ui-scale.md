# UI 尺寸与官方客户端对照

2026-10-13 第一轮。目标是让常读、常点的元素更舒展，沿用现有 macOS 玻璃风格、220pt 侧栏和主窗口播放。

## 对照结论

本机官方哔哩哔哩客户端为 1.19.0。实际查看了推荐、动态（视频与综合）、搜索、收藏、历史、稍后再看、播放简介和评论。静态尺寸来自其 `app.asar` 中的 CSS。CSS px、SwiftUI pt 和 Retina 截图物理像素不同，表格用于比较设计层级，不能当作截图像素的一比一测量。

| 元素 | 官方 CSS 声明 | BiliNext 原来 | 本轮 |
| --- | --- | --- | --- |
| 视频卡片标题 | 通常15，行高22；窄搜索页14 | 14，双行40pt | 16，增加3pt行间距，双行48pt |
| UP 主／辅助信息 | 通常13 | 11–12或系统 caption | 13，封面密集信息12 |
| 普通按钮／输入 | 按钮34pt高度、14字；输入32 | 很多使用默认小尺寸 | 原生 large 控件；自绘控制明确32–34pt区域 |
| 动态正文 | 15／22 | 14 | 16，保留段落和行间距 |
| 播放互动操作 | 24图标、50×60点击块、12标签 | 一排无文字图标 | 22图标、36×60点击块、13标签 |
| 播放选集 | 14字、40行高 | 默认字号 | 14字、最小40行高 |

官方的可读性来自字号、行高、点击块和留白共同作用。此次没有整体缩放界面：大标题保持26pt，主要阅读16pt，普通正文15pt，控件14pt，辅助信息13pt，密集标签12pt。

## 页面调整

- 推荐、视频动态、搜索、收藏、历史和稍后再看共用更宽的视频卡片。最小卡宽由220pt提升为260pt，20pt列间距保持。当前约1500pt窗口由五列变四列；1220pt默认窗口按布局计算为三列。AppKit固定高度同步增加，历史日期和进度可占两行。
- 侧栏主菜单38pt、子菜单34pt、视频标签36pt，文字与图标一起增加尺寸。220pt宽度、菜单顺序、固定／隐藏及边缘悬停揭示保留。
- 播放操作增加可见文字，仍执行原来的点赞、投币、收藏、稍后、缓存和复制当前时间链接。清晰度／速度菜单行高36pt。播放区不超过540pt时，时间移到进度条右侧，保留13pt完整显示。
- 评论改为顶部头像、作者和时间，正文在下方独占整行。缩小逐层缩进，保留回复树、折叠、复制、分页与加载逻辑。
- 字幕脚本正文16pt，搜索和时间跳转区域增大；双语、去换行和智能字幕设置的逻辑与默认值保留。
- 番剧、UP 主主页、登录和下载弹窗同步调整标题、副信息和控件尺寸。

## 验证范围

现有自动测试通过，包括卡片列数边界、宽度与历史高度预算。修改过的 Swift 文件通过严格格式检查，Release 编译通过。签名 Debug App 已打包并验证签名，使用现有本机开发登录方式。

真实暗色窗口检查了推荐、视频／全部动态、搜索、收藏、历史、稍后再看、番剧、UP 主主页、下载列表、播放简介、评论及字幕脚本。浅色／深色共享组件和310pt详情区另做了离屏预览；360pt播放器离屏预览确认长时间完整、全部操作仍可见。离屏预览不能替代真实窗口的玻璃效果检查。
