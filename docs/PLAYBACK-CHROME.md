# 播放页与侧栏交互

播放页移除顶部标题栏，播放器占满中间区域。右侧详情通过播放器右边缘的箭头收起和展开。箭头仅在鼠标位于视频或详情区域时出现；本机播放器播放时随控件闲置隐藏，鼠标同步隐藏，移动后恢复。暂停及设置弹窗保持控件可用。官方核心使用独立的 2.5 秒闲置计时。

返回浏览、切换播放器和在浏览器打开移至详情区域的播放选项菜单。原播放器底部剧场模式按钮仍可展开详情。

左侧保持固定 220pt 宽度和既有菜单顺序。浮动侧栏延续窗口外侧 220pt 唤起区域，增加窗口左侧内沿 3pt，支持全屏贴边唤起。固定与非固定侧栏均采用原生玻璃材质；非固定侧栏保留原有圆角和透明效果。顶部侧栏开关为圆形玻璃按钮，后退、前进与刷新组成玻璃胶囊，保留固定宽度及原有菜单密度。

## 本轮验证

- 默认 `swift test`：17 个离线测试通过，4 个集成测试跳过。
- 新增全屏 x=0、内沿、外侧边界、浮动侧栏范围及离开区域回归测试。
- 格式检查、Debug / Release 编译、App 构建和签名验证通过。
- 实际观察到播放页标题栏消失、深灰侧栏、播放控件闲置隐藏和侧栏收起。
- 用户实际试用后反馈可以正常工作；自动操作工具无法可靠移动鼠标到窗口边缘，因此未独立确认全屏贴边和两种核心的完整悬停组合。

## 玻璃控件与顶部留白

详情栏目改为原生玻璃胶囊，选中项平滑移动，并响应系统减少动态效果设置。三点菜单采用圆形玻璃外观。详情区域忽略顶部额外安全区，以 8pt 纵向留白排列控件；不恢复原播放页标题栏。

参考 Apple 的原生 glassEffect / GlassEffectContainer 文档，以及以下项目的原生玻璃与控件分组思路，未增加依赖：
- https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views
- https://github.com/SohrabZ/swiftui-macos-app
- https://github.com/metneo/LiquidGlass

格式、Debug / Release 编译与签名检查通过，离线测试 17 个通过、集成测试 4 个跳过。实际确认顶部留白缩小、侧栏按钮分组可见、栏目切换可用以及三点菜单可以打开与关闭。
