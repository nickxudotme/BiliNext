# 页面实例保留

主窗口按页面保留视图与模型：六个浏览入口各自一个实例，打开过的视频标签各自一个实例。切换使用同一视图身份，仅改变可见性和输入权限，因此页面内的滚动位置、筛选、详情选项和已加载内容保留。显式刷新仍会更新当前页面。

视频标签各自拥有 AVPlayer、媒体资源桥、播放时钟、弹幕、字幕及异步任务。切换时暂停后台页，加载或清晰度切换尚未结束的后台页也不能自动恢复播放。关闭和清空时释放对应媒体资源，撤销关闭恢复标签记录，重新激活后加载媒体。

页面共用账号 API 会话与下载管理。高频播放时钟不转发到整个工作区，只转发播放状态变化与全局提示。后台浏览页不触发瀑布流自动加载。

本次保留的是应用运行期间的实例。退出应用后继续沿用原有标签、分 P 和播放位置 JSON；不把视图或播放器序列化到磁盘。浏览列表与滚动位置尚未增加跨重启恢复。

验证：临时目录测试覆盖浏览实例身份、筛选与列表隔离、消息转发、独立播放器、多个标签的会话保存及关闭释放；公开视频静音实播覆盖两页切换、媒体实例保持、播放位置与倍速保持、后台暂停、关闭另一标签。运行 `BILINEXT_DASH_TEST=1 swift test --filter playbackTabSwitchRetainsLoadedMedia` 可重复实播验证。内嵌官方核心的多页切换尚未单独实播验证。

签名 App 实际检查：首页滚动条设置到 0.35，切到动态再回首页，滚动条仍为 0.35，且原列表内容保持。27 个离线测试通过，6 个可选联网测试默认跳过；Debug、Release、格式及签名检查通过。
